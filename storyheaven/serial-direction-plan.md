# 작품 방향별 재미와 유머 설계

- 작성일: 2026-09-07
- 선행 계획: `serial-quality-v3-plan.md`
- 적용 대상: 새 설정에서 선택한 작품 방향과 해당 설정으로 새로 기획하는 작품

## 원칙

재미는 웃음과 같지 않다. 진중한 서사는 긴장, 존엄, 성취, 경이, 복수의 카타르시스로 독자를 붙잡는다. 웃음이 없는 작품을 낮게 평가하거나 관계 장면에 농담을 강요하지 않는다. 작품 방향은 문체의 유머 권고와 웃음 강도보다 우선하며, 확정한 방향은 설정집에 저장해 다음 화와 재개에서도 유지한다.

처절한 성장과 복수는 손실과 생존, 수련과 선택, 미리 단서가 있는 기연, 폭발적 성장, 압도적인 복수와 그 이후 결과를 장기 구조에 배분한다. 기연과 압도적 승리를 정당한 보상으로 허용한다. 복수 직전 임의 약화나 새 적을 반복해 약속한 결말을 미루지 않는다. 기연의 획득과 힘의 규칙에는 개연성을 요구하되, 매 승리에 새로운 대가를 붙여 성취를 취소하지 않는다.

## 구현 순서

1. [완료] 서버 소유 작품 방향: 문체에 맞춤, 유쾌한 모험, 진중한 서사, 처절한 성장과 복수. 웃음 0을 허용하고 진중한 방향에서는 유머 적용값을 0으로 확정한다. 기존 정책에 방향이 없으면 소급 적용하지 않는다.
2. [완료] 방향을 후보 기획, 문체 오디션, 설정집, 장기 전개, 회차, 집필, 보완, 모든 검수에 전달한다. 작품에 고정된 방향을 후속 일정 변경보다 우선한다.
3. [완료] 방향별 회차 계획: 중심 보상과 지켜야 할 감정, 선택적인 유머 장면. 유머 장면에는 인물의 목적 충돌, 사전 기대, 어긋남, 반응과 반복 식별자를 둔다. 무유머 작품은 빈 유머 목록으로 정상 통과한다.
4. [완료] 기존 검수에 방향 적합성과 실제 원문 근거를 추가한다. 웃음 유무 자체를 합격 기준으로 쓰지 않고 억지 농담, 감정 훼손, 방향 이탈을 검사한다. 새 검수 호출은 추가하지 않는다.
5. [완료] 최근 유머 계획을 회차 기억에 저장해 같은 방식의 반복을 피하고, 보완 시 기대와 반응의 연결을 보존한다. 실제 웃음 효과로 입증되지 않은 계획은 성공 사례로 기록하지 않는다.
6. [완료] 운영 화면의 등록, 임시 저장, 불러오기, 중지·시작에 같은 방향을 보존한다. 신규 입력은 자동 맞춤이며 자세한 원칙은 도움말에서 확인한다.
7. [완료] 서버 계약, 구형 정책 호환, 진지한 복수극과 유쾌한 모험의 전 단계 프롬프트, 모바일·PC 설정 저장을 검증한다.

## 검증 기준

- 웃음 0, 진중한 방향에 웃음 5를 입력한 경우에도 최종 적용은 무유머다.
- 진중한 작품의 높은 품질과 유머 없는 장면은 정상 승인 가능하다.
- 유머가 허용된 작품도 상실·복수 결행·생존 위기 장면에 유머를 강제하지 않는다.
- 실제 원문에 없는 검수 인용은 거부하며 점수와 무관하게 방향 이탈을 보완한다.
- 유머 계획이 저장·재조회·다음 회차 기억으로 이어지고, 무유머 작품에는 농담 기억을 요구하지 않는다.
- 문체 랜덤을 확정한 뒤 자동 방향도 같은 결과로 재사용된다.
- 기존 공개 원고와 테스트 예약은 변경하거나 재가동하지 않는다.

## 후속 품질 평가

구현 검증 뒤 같은 사건을 유지한 짧은 비공개 장면 비교로 자연스러움, 인물 매력, 감정 보존과 장르 보상을 확인한다. AI 점수는 편집 보조 지표이며 실제 독자의 웃음이나 만족을 보장하지 않는다. 비교 생성과 독자 반응 확인은 별도 운영 검증으로 남긴다.
