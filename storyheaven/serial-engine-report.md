# 스토리천국 장기 연재 엔진

## 독자 약속

대상 독자는 중학생부터 성인까지입니다. 작품은 어렵게 보이는 문장보다 빠르게 이해되는 장면, 장르의 재미, 다음 화가 궁금해지는 질문을 우선합니다. 시간·기간·나이·층수처럼 독자가 즉시 식별해야 하는 수치는 `8초`, `11년`, `5살`, `지하 13층`처럼 씁니다. `한 번`, `두 사람`, `세 번째`처럼 한국어 문장 안에서 자연스러운 세기는 한글을 유지합니다.

## 왜 거대한 한 번의 프롬프트로 만들지 않는가

한 모델이 세계관, 장기 줄거리, 회차 원고, 검수까지 한 번에 맡으면 앞에서 만든 설정을 뒤에서 바꾸기 쉽고 자기 원고의 문제도 놓칩니다. 대신 설정집과 복선 장부는 별도 데이터로 고정하고, 회차마다 `기획 -> 집필 -> 기계 검사 -> 독립 편집 검수 -> 필요한 장면만 재작성 -> 설정 반영` 순서로 자동 처리합니다. 운영자가 회차마다 승인하지 않습니다.

## 운영자가 정하는 것

운영자는 기본 장르 1~3개와 장르별 세부장르 전체 1~10개, 새 작품 기획 주기, 공개 모드와 창작 강도 프리셋을 정합니다. 각 기본 장르는 현재 연재 시장에서 반복적으로 쓰이는 독자 기대와 이야기 장치를 기준으로 세부장르 10개를 제공합니다. 복합 장르는 첫 장르가 회차 엔진을 맡고 나머지 장르가 관계·갈등·세계 규칙·정서 중 서로 다른 역할을 맡아 하나의 인과적인 작품으로 결합됩니다. 선택한 장르는 단순 태그가 아니라 세계 규칙, 갈등 종류, 독자가 기대하는 보상, 문체와 전개 속도를 만드는 기초 제약입니다.

기본 장르와 세부장르에는 각각 `랜덤`이 있습니다. 랜덤은 다른 항목과 섞이지 않는 배타 선택이며 서버가 일정 생성 시 실제 장르를 한 번 확정합니다. 이후 설정집과 회차마다 다시 뽑지 않으므로 작품 정체성이 중간에 바뀌지 않습니다.

창작 강도는 기본적으로 `균형`, `빠른 몰입`, `감정 중심` 중 하나만 고릅니다. 상세 조정이 필요할 때 전개 속도, 긴장, 호기심, 반전, 감정 진폭, 관계·로맨스, 액션, 묘사 밀도, 웃음, 참신성을 1~5로 조절할 수 있습니다. 참신성 기본값은 `2 · 절제된 차별화`입니다. 이 단계에서는 독자가 아는 장르 문법과 인간적인 갈등을 약 80% 유지하고 작품을 구분하는 규칙·관계·대가 중 하나만 선명하게 더합니다. 서로 무관한 직업·생활용품·마법 규칙을 억지로 섞거나 매 화 새 기믹을 추가하는 방식은 참신성으로 인정하지 않습니다. `4~5`는 운영자가 의도적으로 실험적인 작품을 만들 때만 사용합니다. 이 값들은 모든 장면을 같은 세기로 만드는 명령이 아니라 작품 전체의 평균 목표입니다. 높은 축에도 회복 장면을 두며, 반전에는 사전 단서가 필요하고 높은 묘사는 장식적 나열이 아니라 공간과 행동을 이해시키는 구체물에 사용합니다. 사회풍자는 취약한 사람 대신 제도, 권력, 보상 구조와 위선을 대상으로 합니다.

- `테스트 비공개`: 집필과 검수를 자동 진행하고 운영자가 선택한 1~10화를 비공개로 쌓습니다. 기본값은 1화입니다.
- `자동 공개`: 선택한 회차까지 순서대로 공개합니다. 이후에는 최신 회차의 독자 추천이 11개에 도달하거나 운영자가 `다음 화 작성`을 요청할 때 한 화씩 이어 씁니다.
- `멈춤`: 새 집필과 예약 공개를 함께 멈춥니다. 이미 공개된 글은 유지합니다.

## 회차 제작 흐름

1. 한 줄 독자 약속과 익숙한 재미 하나, 새로운 변주 하나를 먼저 통과시킵니다.
2. 세계 규칙, 인물의 욕망과 비밀, 인물별 현재 지식, 시간선을 설정집에 기록합니다.
3. 설정한 전체 권수만큼 권별 시작 상태·목표·중반 전환·절정·되돌릴 수 없는 변화·다음 권 연결을 전부 작성합니다. 권당 본편 화수는 겹치거나 비지 않는 고정 범위로 계산합니다.
4. 최소 5개의 반복 가능한 갈등 원천, 모든 권을 덮는 인물 성장 단계, 중반과 후반과 최종권까지 분산된 장기 복선을 설정합니다. 프롤로그에서 답을 밝히면 안 되는 복선은 별도 공개 제한표로 잠급니다.
5. 한 회차를 3~5개 장면으로 나누고 각 장면에 목표·충돌·변화를 지정합니다. 최근 3화와 같은 도입·후킹 조합은 피합니다.
6. 작품별 문체 카드에 따라 초고를 작성합니다. 실존 작가의 문체는 모사하지 않습니다.
7. 숫자 표기, 반복 어미, 비정상 장문, 금칙 패턴, 코드 삽입을 기계적으로 검사합니다.
8. 생성 이유를 보지 않은 별도 편집자 역할이 설정, 인과관계, 한국어, 재미, 진부함을 근거와 함께 평가합니다.
9. 문제가 있는 장면만 최대 2회 다시 씁니다. 계속 실패하면 공개하지 않고 보류합니다.
10. 통과한 회차에서 새로 생긴 사실, 인물 상태, 복선과 시간선을 설정 장부에 반영합니다.
11. 두 모드 모두 설정한 목표 회차까지 자동으로 제작합니다. 목표 이후에는 최신 회차마다 독자 추천 11개 또는 운영자 요청을 확인하고 한 화만 추가합니다.
12. 프롤로그는 핵심 규칙과 즉시 사건은 만족스럽게 보여주되, 장기 복선의 답·최종 상대·최종 결말·후반 성장 단계는 공개하지 않습니다. 보호된 복선을 `revealed`로 처리하려는 원고는 서버 검증에서도 거부합니다.
13. 1화 완료 시간은 설정별 표본 수, 최근 시간, 누적 평균으로 DB에 저장합니다. 자동 연재 실행 기록에서는 아이디어, 설정집, 장기 전개, 회차 구성, 원고 작성, 편집 검수의 개별 소요 시간을 확인합니다.

## 합격 기준

| 항목 | 기준 |
| --- | ---: |
| 한국어 가독성 | 85점 이상 |
| 설정 일치 | 95점 이상 |
| 인과관계 | 90점 이상 |
| 초반 흡입력 | 75점 이상 |
| 전개 추진력 | 80점 이상 |
| 감정 보상 | 75점 이상 |
| 장르 약속 | 80점 이상 |
| 다음 화 궁금증 | 80점 이상 |
| 주인공의 능동성 | 75점 이상 |
| 참신성 설정 적합도 | 65점 이상 |
| 안전성 | 반드시 통과 |

설정 충돌, 안전 문제, 행동의 원인이 빠진 경우는 필수 재작성 대상입니다. 각 점수에는 원고의 실제 근거를 1~4개 붙입니다. 참신성은 낯설수록 높은 점수를 주는 항목이 아니라 운영자가 정한 단계에 맞는지를 평가합니다. 독자 체감 점수는 흡입력·추진력·감정 보상·장르 만족·궁금증·능동성·참신성 적합도를 가중 합산하지만, 합계가 높아도 개별 기준 미달이 있으면 재작성합니다. 표현 하나가 어색한데 전체 회차를 다시 쓰는 낭비는 막습니다.

프롤로그에는 더 높은 별도 기준을 적용합니다. 초반 흡입력 90점, 다음 장면·다음 화 궁금증 92점, 참신성 설정 적합도 70점, 장르 약속 88점, 전개 추진력 86점이 모두 넘어야 합니다. 설정을 이름으로만 설명하거나 무관한 소재를 조합한 원고는 신선한 설정으로 보지 않습니다. 첫 장면에서 작품의 차별점이 실제 사건과 선택을 바꾸고, 회차 안에서 최소 한 번의 장르 보상을 준 뒤 더 큰 질문을 남겨야 통과합니다.

## 자동 실행과 운영 방법

1. 운영자는 기본 장르·세부장르·목표 회차·다음 새 작품까지 기다릴 시간을 고르고 `제작을 대기열에 추가`를 누릅니다.
2. 서버는 기본 60초마다 예약 시각을 확인합니다. 운영 화면 상단에는 실제 서버 확인 주기가 표시됩니다.
3. 대기열은 전역 1개이므로 현재 작품이 끝난 뒤 다음 요청을 순서대로 시작합니다. 같은 일정을 반복 실행해도 진행 중인 작업을 재사용해 중복 작품을 만들지 않습니다.
4. 목표가 1화여도 아이디어, 설정집, 장기 전개를 먼저 만든 뒤 1화를 구성·집필·검수합니다. 목표가 여러 화여도 같은 설정집을 사용해 목표 회차까지 순서대로 진행합니다.
5. 완료 뒤 설정한 분·시간이 지나면 활성 일정이 다음 새 작품을 예약합니다. `멈춤`은 이후 예약만 중지하며 이미 공개된 회차는 유지합니다.
6. 운영 화면은 `진행 중`, `대기`, `완료`, `확인 필요`를 분리합니다. 현재 작업은 6초마다 갱신되며 아이디어, 설정집, 장기 전개와 회차별 구성·원고·검수 중 어디까지 왔는지 표시합니다. 모든 시각은 `Asia/Seoul` 기준으로 날짜와 함께 표시합니다.
7. 완료 원고는 최근 완료 목록의 `원고·검수 보기`를 눌렀을 때만 아래 확인 영역에 펼쳐집니다. 과거 실행의 단계별 시간과 오류는 기본 접힘 상태인 이전 실행 기록에서 필요할 때만 확인합니다. 성공한 1화의 전체 시간은 표본에 누적되어 `평균 1화 작업 예상 시간`으로 표시됩니다.
8. 연결 오류로 작업이 완전히 중단되면 `확인 필요`에 같은 일정의 최신 실패 한 건만 표시됩니다. `중단 지점부터 재개`를 누르면 완료된 설정집과 기획은 그대로 두고 실패한 AI 단계만 다시 대기시킵니다. 생성 절차는 끝났지만 편집 기준을 넘지 못한 원고도 `품질 보류`로 같은 영역에 표시하되, 재실행 버튼 대신 `검수 결과 보기`를 제공합니다. 더 오래된 중단 시도는 현재 상태와 섞지 않고 접힌 기록으로만 보관합니다.

초기 운영은 목표 1화, 테스트 비공개, 2시간 간격을 기본값으로 사용합니다. 최소 5개 작품의 1화 완료 시간과 품질 기록이 쌓인 뒤 평균 시간보다 짧게 주기를 잡지 않는 편이 안정적입니다. 공개 전에는 1화의 흡입력 근거와 마지막 질문을 품질 기록에서 확인하고, 반응이 좋은 장르 조합만 목표 회차를 2~3화로 늘립니다.

## 다양한 진행 기법을 단순하게 운용하는 법

시간순 진행, 사건 한가운데서 시작, 미래 장면 선공개, 결과 우선 도입, 이중 시간선, 증언 액자 구조, 신뢰할 수 없는 시점, 극적 아이러니, 평행 장면, 카운트다운, 잘못된 단서, 설정과 회수, 도덕적 딜레마, 콜백, 시점 전환을 작품 설정집에 후보로 둡니다. 회차 기획자는 그중 이번 사건을 가장 선명하게 만드는 한두 가지만 고르고 이유를 기록합니다. 비선형 구성은 시간순 구성보다 질문이 더 분명해질 때만 사용합니다.

## 작품마다 다른 글맛

작품별 문체 카드는 서술 거리, 문장 호흡, 대화 비율, 유머 방식, 묘사 밀도, 감정 표현, 피해야 할 어미와 상투구를 보관합니다. 공개 작품끼리 반복되는 어절, 도입 방식, 문장 끝맺음을 비교해 같은 사람이 쓴 듯한 흔적도 확인합니다. 차이는 난해한 단어가 아니라 정보의 순서와 리듬으로 만듭니다.

## 구현 순서

- 1단계 완료: 공개 12개 회차 한국어 교정과 자동 회귀 검사
- 2단계 완료: Oracle 설정집·장기축·회차 카드·복선 장부, 내부 작성·검수 API
- 3단계 완료: 작가와 편집자 분리 실행, 국소 재작성, 순차 예약 공개, 작품 건강도 운영 화면

운영 화면에서 `자동 연재 시작`을 누른 활성 일정만 작품을 만듭니다. 이후에는 회차별 사람 승인이 없습니다. 회차는 마지막 공개 또는 비축 회차의 바로 다음 번호만 만들고, 공개도 마지막 공개 회차의 다음 번호만 가능하므로 실패한 회차를 건너뛰어 뒷이야기가 먼저 노출되지 않습니다.

상세 구조와 데이터 테이블은 `webtoon/design-db.json`의 `storyHeavenSerialEngine20260731`을 기준으로 합니다.

## 창작 강도 설계 근거

긴장만 높이는 단일 슬라이더로는 독서 경험을 설명하기 어렵습니다. 서사 긴장은 서스펜스, 놀라움, 호기심의 상호작용으로 설명할 수 있고, 흥미에는 서스펜스뿐 아니라 이야기의 일관성과 주제 복잡성도 영향을 줍니다. 그래서 긴장·호기심·반전을 분리하고, 인과를 보호하기 위해 강도를 평균 목표로만 사용합니다.
