# 스토리천국 장기 연재 엔진

## 독자 약속

대상 독자는 중학생부터 성인까지입니다. 작품은 어렵게 보이는 문장보다 빠르게 이해되는 장면, 장르의 재미, 다음 화가 궁금해지는 질문을 우선합니다. 시간·기간·나이·층수처럼 독자가 즉시 식별해야 하는 수치는 `8초`, `11년`, `5살`, `지하 13층`처럼 씁니다. `한 번`, `두 사람`, `세 번째`처럼 한국어 문장 안에서 자연스러운 세기는 한글을 유지합니다.

## 왜 거대한 한 번의 프롬프트로 만들지 않는가

한 모델이 세계관, 장기 줄거리, 회차 원고, 검수까지 한 번에 맡으면 앞에서 만든 설정을 뒤에서 바꾸기 쉽고 자기 원고의 문제도 놓칩니다. 대신 설정집과 복선 장부는 별도 데이터로 고정하고, 회차마다 `기획 -> 집필 -> 기계 검사 -> 독립 편집 검수 -> 필요한 장면만 재작성 -> 설정 반영` 순서로 자동 처리합니다. 운영자가 회차마다 승인하지 않습니다.

## 운영자가 정하는 것

운영자는 기본 장르 1~3개와 장르별 세부장르 전체 1~10개, 새 작품 기획 주기, 공개 모드만 정합니다. 각 기본 장르는 현재 연재 시장에서 반복적으로 쓰이는 독자 기대와 이야기 장치를 기준으로 세부장르 10개를 제공합니다. 복합 장르는 첫 장르가 회차 엔진을 맡고 나머지 장르가 관계·갈등·세계 규칙·정서 중 서로 다른 역할을 맡아 하나의 인과적인 작품으로 결합됩니다. 선택한 장르는 단순 태그가 아니라 세계 규칙, 갈등 종류, 독자가 기대하는 보상, 문체와 전개 속도를 만드는 기초 제약입니다.

기본 장르와 세부장르에는 각각 `랜덤`이 있습니다. 랜덤은 다른 항목과 섞이지 않는 배타 선택이며 서버가 일정 생성 시 실제 장르를 한 번 확정합니다. 이후 설정집과 회차마다 다시 뽑지 않으므로 작품 정체성이 중간에 바뀌지 않습니다.

코미디는 `개그·슬랩스틱`과 `사회풍자`를 구분하고 웃음 강도를 별도로 정합니다. `미소 중심`은 본편 80%·웃음 20%, `균형`은 60%·40%, `웃음 우선`은 35%·65%를 목표로 합니다. 이는 글자 수 배분이 아니라 장면의 목적과 보상 비중이며, 설정집의 유머 방식과 반복 금지 규칙으로 저장됩니다. 사회풍자는 취약한 사람 대신 제도, 권력, 보상 구조와 위선을 대상으로 합니다.

- `테스트 비공개`: 집필과 검수를 자동 진행하고 처음 3화를 비공개로 쌓습니다.
- `자동 공개`: 처음 3화를 회차 순서대로 공개합니다. 이후에는 최신 회차의 독자 추천이 11개에 도달하거나 운영자가 `다음 화 작성`을 요청할 때 한 화씩 이어 씁니다.
- `멈춤`: 새 집필과 예약 공개를 함께 멈춥니다. 이미 공개된 글은 유지합니다.

## 회차 제작 흐름

1. 한 줄 독자 약속과 익숙한 재미 하나, 새로운 변주 하나를 먼저 통과시킵니다.
2. 세계 규칙, 인물의 욕망과 비밀, 인물별 현재 지식, 시간선을 설정집에 기록합니다.
3. 시즌의 중심 질문, 중간 반전, 결말의 진실, 복선 회수 시점과 도입·창작 기법 순환 규칙을 정합니다.
4. 한 회차를 3~5개 장면으로 나누고 각 장면에 목표·충돌·변화를 지정합니다. 최근 3화와 같은 도입·후킹 조합은 피합니다.
5. 작품별 문체 카드에 따라 초고를 작성합니다. 실존 작가의 문체는 모사하지 않습니다.
6. 숫자 표기, 반복 어미, 비정상 장문, 금칙 패턴, 코드 삽입을 기계적으로 검사합니다.
7. 생성 이유를 보지 않은 별도 편집자 역할이 설정, 인과관계, 한국어, 재미, 진부함을 근거와 함께 평가합니다.
8. 문제가 있는 장면만 최대 2회 다시 씁니다. 계속 실패하면 공개하지 않고 보류합니다.
9. 통과한 회차에서 새로 생긴 사실, 인물 상태, 복선과 시간선을 설정 장부에 반영합니다.
10. 두 모드 모두 처음 3화까지만 자동으로 비축합니다. 4화부터는 최신 회차마다 독자 추천 11개 또는 운영자 요청을 확인하고 한 화만 추가합니다.

## 합격 기준

| 항목 | 기준 |
| --- | ---: |
| 한국어 가독성 | 85점 이상 |
| 설정 일치 | 95점 이상 |
| 인과관계 | 90점 이상 |
| 초반 흡입력 | 75점 이상 |
| 전개 추진력 | 80점 이상 |
| 감정 보상 | 75점 이상 |
| 장르 약속 | 80점 이상 |
| 다음 화 궁금증 | 80점 이상 |
| 주인공의 능동성 | 75점 이상 |
| 새로움 | 75점 이상 |
| 안전성 | 반드시 통과 |

설정 충돌, 안전 문제, 행동의 원인이 빠진 경우는 필수 재작성 대상입니다. 각 점수에는 원고의 실제 근거를 1~4개 붙입니다. 독자 체감 점수는 흡입력·추진력·감정 보상·장르 만족·궁금증·능동성·참신성을 가중 합산하지만, 합계가 높아도 개별 기준 미달이 있으면 재작성합니다. 표현 하나가 어색한데 전체 회차를 다시 쓰는 낭비는 막습니다.

## 다양한 진행 기법을 단순하게 운용하는 법

시간순 진행, 사건 한가운데서 시작, 미래 장면 선공개, 결과 우선 도입, 이중 시간선, 증언 액자 구조, 신뢰할 수 없는 시점, 극적 아이러니, 평행 장면, 카운트다운, 잘못된 단서, 설정과 회수, 도덕적 딜레마, 콜백, 시점 전환을 작품 설정집에 후보로 둡니다. 회차 기획자는 그중 이번 사건을 가장 선명하게 만드는 한두 가지만 고르고 이유를 기록합니다. 비선형 구성은 시간순 구성보다 질문이 더 분명해질 때만 사용합니다.

## 작품마다 다른 글맛

작품별 문체 카드는 서술 거리, 문장 호흡, 대화 비율, 유머 방식, 묘사 밀도, 감정 표현, 피해야 할 어미와 상투구를 보관합니다. 공개 작품끼리 반복되는 어절, 도입 방식, 문장 끝맺음을 비교해 같은 사람이 쓴 듯한 흔적도 확인합니다. 차이는 난해한 단어가 아니라 정보의 순서와 리듬으로 만듭니다.

## 구현 순서

- 1단계 완료: 공개 12개 회차 한국어 교정과 자동 회귀 검사
- 2단계 완료: Oracle 설정집·장기축·회차 카드·복선 장부, 내부 작성·검수 API
- 3단계 완료: 작가와 편집자 분리 실행, 국소 재작성, 순차 예약 공개, 작품 건강도 운영 화면

운영 화면에서 `자동 연재 시작`을 누른 활성 일정만 작품을 만듭니다. 이후에는 회차별 사람 승인이 없습니다. 회차는 마지막 공개 또는 비축 회차의 바로 다음 번호만 만들고, 공개도 마지막 공개 회차의 다음 번호만 가능하므로 실패한 회차를 건너뛰어 뒷이야기가 먼저 노출되지 않습니다.

상세 구조와 데이터 테이블은 `webtoon/design-db.json`의 `storyHeavenSerialEngine20260731`을 기준으로 합니다.
