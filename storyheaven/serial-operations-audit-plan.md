# 자동 연재 운영 안정화 점검

작성일: 2026-09-20. 기준: 기획 → 설정 → 회차 작성 → 검수/보완 → 첫 3편 동시 공개, 후속 연재는 운영자 결정.

## 확인된 문제

1. 실패 작업과 대기 작업이 함께 있으면 재개가 대기 작업만 깨우고 실패 작업을 그대로 남긴다.
2. 실행 권한 만료로 재시도 횟수를 소진해도 상위 작업이 계속 실행 중으로 남을 수 있다.
3. 오래된 작품을 재보완하면 최초 작품 생성일로 순서를 정해 현재 진행 중인 다른 작품 사이에 끼어든다.
4. 전체 중지가 서버 메모리에만 있고 전체 다시 시작이 개별 중지 설정까지 활성화한다.
5. 공개 전 확인 목록은 12건으로 제한되며, 본편 1·2화 검수 보류도 프롤로그 미완성처럼 표시한다. 한 설정의 과거 오류를 숨기는 방식 때문에 작품별 조치 누락도 가능하다.
6. 자동 재시도 대기, 설정 중지, 정상 순서 대기를 모두 같은 대기로 표시한다. 확인 필요와 공개 전 확인에서 같은 작품이 중복될 수 있다.
7. 오래된 화면 조회 응답이 최신 조작 결과를 덮어쓸 수 있고, 완료된 실행 이력에 현재 진행 작업도 중복 표시된다.
8. 오래 걸리는 AI 호출의 실행 권한을 연장하는 기능이 없고, 중지 명령이 실제 호출에 전달되지 않아 불필요한 실행이 계속될 수 있다.
9. 첫 3편 공개 후 별도 작품 설정이 없으면 추천 기반 후속 연재가 기본값으로 적용된다. 공개 승인과 이후 연재 결정이 분리되어야 한다.

## 구현 및 검증 순서

- [x] DB에 전체 중지 상태와 현재 처리 묶음을 저장하고 단일 작업 가져오기를 직렬화한다.
- [x] 재접수 시각 기준 순서를 저장하며 이미 시작한 제작 묶음은 끝날 때까지 유지한다.
- [x] 만료/실패 상태를 상위 작업에 반영하고 오류가 있는 작업은 재개 전 실행 대상에서 제외한다. 재개는 오류와 남은 대기 단계를 함께 복구한다.
- [x] 목록을 작품별 조치 중심으로 통합하고 현재 회차·중단 이유·다음 조치를 표시한다. 전체 보류 건수와 표시 범위를 알려 숨겨진 건을 오인하지 않게 한다.
- [x] 전체 시스템 상태, 진행 중 1건, 순서 대기, 조치 필요, 완료 기록 순서로 화면 표현을 정리한다.
- [x] 실행 권한을 주기적으로 연장하고 중지 요청 시 실행 프로세스에 중단을 전달한다. 완료 응답 재전송은 중복 저장하지 않는다.
- [x] 첫 3편의 공개 승인은 세 편의 공개만 승인하며, 별도 후속 연재 설정이 없는 작품은 운영자 요청 방식으로 보관한다.
- [x] 계약/상태 전환 검사와 데스크톱·모바일 운영 시나리오, Oracle 롤백 검증 후 배포한다.

## 운영 기준

정상 대기는 기다리면 되고, 자동 재시도는 남은 시각을 보여준다. 실패를 소진한 작업은 중단 이유와 '중단 단계 재개'를 제공한다. 품질 보류는 현재 회차와 반드시 고칠 항목을 보여주며 '선택 원고 보완'으로 묶어 처리한다. 전체 중지는 개별 설정을 변경하지 않는 별도 차단이다. 과거 원고/로그를 삭제하거나 자동 승인 기준을 낮추지 않는다.

## 검증 결과

- 신규 상태 전환 검사: 오류와 대기 검수가 함께 있는 재개, 재접수 순서, 진행 묶음 유지, 개별 중지 보존, 전체 중지 조회, 실행 만료, 완료 응답 재전송, 연결 일시 실패와 실행 권한 회수 통과.
- Oracle 롤백 검사: 대기열 조회, 본편 보류 표시, 오류/대기 동시 재개, 동시 DB 잠금, 전체 중지 차단, 만료된 작업의 상위 오류 반영 통과. 임시 작업과 상태 변경은 롤백했다.
- 브라우저: 13개 보류 작품 표시, 본편 회차명, 중복 조치 제거, 자동 재시도/설정 중지 구분, 부분 선택 후 일부 접수 실패 및 재접수, 모바일/데스크톱 가로 넘침 검사 통과.
- 서버 적용: 실제 작업 1건 진행·7건 순서 대기, 실행 묶음 일치, 주기적 실행 확인과 15분 실행 권한 연장을 확인했다. 개별 호출 완료 후 작업자를 교체했다.
- 후속 연재: 첫 3편이 공개된 작품 중 별도 설정이 없는 경우만 운영자 요청 방식으로 설정했다. 명시적으로 저장된 작품 설정은 변경하지 않았다.
- 응답 지연은 목록 조회 20초, 조작 60초 후 안내하며, 접수 여부가 불확실하면 재전송을 단정하지 않고 상태 확인을 안내한다.
- 배포된 화면에 읽기 전용 운영 데이터 스냅샷을 연결해 320/390/1440px에서 조치 목록 11건, 현재 제작 상태, 가로 넘침 0, 브라우저 오류 0을 확인했다. 실제 서버에 작업 요청이나 승인을 보내지 않았다.
- 긴 영문 검수 항목의 모바일 줄바꿈, 밝은 배경 위 희미한 설명 글자, 과도한 페이지 제목 크기를 추가 개선했다.
