# StoryHeaven 품질·독서·커뮤니티 개선 계획

작성일: 2026-09-20. 선행: serial-quality-v2/v3/v4-plan.md, serial-direction-plan.md.

## 진단과 방향

v2의 장편 설계·다중 비평, v3의 장르·문체 분리, v4의 인과 체크포인트·누적 보완은 유지한다. 현재의 큰 문제는 높은 점수 자체보다 회차 간 사실 전달, 재작성 중 해결된 지적의 보존, 실제 독자가 읽는 흐름이다. 승인 계산은 미해결 보완 항목도 직접 검사해야 한다. 독서 화면에는 회차 이동 경쟁 요청과 댓글 요청의 이전 회차 응답이 늦게 도착하는 문제도 함께 점검한다.

## 집필 품질

- 최근 2개 선행 회차의 검수 통과 원고에서 마지막 문단들을 분량 상한 내에 전달한다. 공개 전 파일럿도 승인된 초고만 사용할 수 있다. 현재 회차와 미래 회차, 탈락 원고는 제외한다.
- 원고 발췌와 출처 회차 번호를 설정집과 분리해 전달한다. 끝 장면의 위치·소지품·정보·감정 상태를 이어 받고, 다음 장면은 인물의 선택과 결과로 전진시킨다.
- 판타지의 새 규칙을 늘리거나 행정 절차를 반복해 분량을 채우지 않는다. 이해 가능한 목표·갈등·보상에 집중하고, 작품 방향이 진중하거나 복수이면 유머를 강제하지 않는다.
- 미해결 수정 의무, 누락된 점수, 안전성 실패는 자동 승인으로 우회할 수 없다. 검수 점수는 실제 독자 반응을 대신하지 않으며, 개선 효과는 이후 보류율과 사람이 읽은 결과로 평가한다.
- 기존 실행 중 작업과 구형 데이터에 새 필드를 일괄 강제하지 않는다. 새 작업을 만들 때 적용한다.

## 운영과 독서

- 서버 접수 전에는 '접수 중', 영속 저장 후에는 '대기열 등록 완료'로 구별한다. 요청이 끝나기 전 화면 이동이 안전하다고 약속하지 않는다.
- 읽기 화면은 밝은 종이·부드러운 회색·야간 배경, 명조/고딕, 글자 크기와 줄 간격을 기기에 저장한다. 큰 제목 대신 본문에 집중할 수 있는 읽기 모드를 제공한다.
- 하단에는 이전 화·목차·설정·댓글·다음 화를 둔다. iPhone 안전 영역, 44px 터치 목표, 긴 제목과 320px 화면을 검사한다.
- 회차를 빠르게 바꿔도 마지막 선택만 화면에 반영하고, 이전 회차 댓글 요청은 새 회차를 덮어쓰지 않는다.

## 댓글 운영

- 댓글·답글은 서버에서 동일한 욕설 규칙을 적용한다. 유니코드·제로폭·구분기호 우회를 정규화하되 정상 단어 오탐을 테스트한다.
- 명확한 욕설은 등록을 거절하고 작성 내용은 유지한다. 기존 댓글은 출력 시 필터링한다. 사전식 검사는 모든 문맥의 모욕을 판별할 수 없으므로 신고와 관리자 숨김을 함께 제공한다.
- 작성자는 자기 댓글 삭제, 운영자는 신고 목록에서 숨김/기각을 수행한다. 신고 원문은 관리자에게만 보이고 일반 독자에게는 숨김 안내만 보인다. 답글이 있으면 부모 자리표시자를 유지한다.
- 목록은 페이지 단위로 더 불러오고 회차별 대화와 답글 대상을 명확히 유지한다.

## 참고 근거

- [DOC, ACL 2023](https://aclanthology.org/2023.acl-long.190/): 세부 계획과 계획 준수를 함께 다루는 장편 생성 연구. 현재 설계/원고 동기화 개선의 참고이며 모델의 문학적 품질을 보증하지 않는다.
- [DOME, NAACL 2025](https://aclanthology.org/2025.naacl-long.63/): 동적 계획과 시간 정보를 가진 기억을 결합한다. 이번 구현은 기존 DB의 승인 원고를 제한적으로 검색하는 경량 접근이며 논문의 전체 시스템을 재현하지 않는다.
- [W3C Reflow](https://www.w3.org/WAI/WCAG21/Understanding/reflow.html), [Text Spacing](https://www.w3.org/WAI/WCAG21/Understanding/text-spacing), [Target Size](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html): 좁은 화면, 사용자 글자/간격 조정, 터치 영역 검증 기준.

## 검증 결과

- API/작업자 검사와 신규 품질·댓글 계약 검사를 통과했다. 미해결 수정 의무와 누락된 점수로는 자동 승인할 수 없다.
- 320/390/1440px에서 명조·고딕, 26px 글자, 2.3 줄 간격, 야간·종이 배경, 설정 재접속 유지, 44px 이상 하단 터치 목표, 빠른 회차 선택 경쟁, 댓글 실패 내용 보존, 답글·신고·삭제·더 보기를 검증했다.
- 운영자 신고 처리 화면과 기존 연재 운영·일괄 보완·독서 회귀 검사도 통과했다. 이미지 기록은 `test-results/storyheaven-book-*`, `storyheaven-comments-*`, `storyheaven-comment-operator.png`에 있다.
- 실제 Oracle에서 댓글 신고 테이블을 적용하고 삭제 권한, 중복 신고, 숨김 처리, 목록 조회를 트랜잭션 안에서 검증한 뒤 모든 테스트 데이터를 롤백했다. 공개 API 댓글 조회는 200, 비로그인 관리자 신고 접근은 401이다.
- 실제 4번째 회차의 작업 입력을 생성해 앞선 2·3번째 회차의 승인 원고 발췌(각 1,719자, 1,695자)가 전달되는 것을 확인한 뒤 작업 생성도 롤백했다. 검증 때문에 원고를 새로 생성하거나 공개하지 않았다.
- 최근 30일 이력 표본 1,809건에 포함된 원본 입력/출력 JSON은 98,208,364글자였다. 화면 이력 조회는 이 본문을 전송하지 않고 검수 역할·모델·토큰 통계만 가져오도록 수정했다. DB 내부 JSON 추출 비용은 남으므로 숫자를 곧바로 응답 시간 개선율로 해석하지 않는다.
- 작성 작업자는 현재 AI 호출 완료 후 정상 종료하고 새 정책으로 시작했다. 새로 대기열에 생성되는 작업부터 적용한다.
- 향후 운영 원고의 재미, 자연스러움, 재보완률 개선은 아직 실측하지 않았다. 시스템 검증 통과를 문학적 품질 보증으로 표현하지 않는다.
